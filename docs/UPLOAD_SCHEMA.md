# عقد الداتا — `upload.csv` (الإصدار 1)

ده الملف اللي سكريبت الرفع على سوفتك بيقراه. سطر لكل صنف في فاتورة. الترميز UTF-8 مع BOM (يفتح في Excel مباشرة).
**الثقة**: ✅ اتحقق منه بحساب أو بمقارنة بسوفتك · 🟡 بيتقرا بدقة جيدة لكن بيغلط أحيانًا (راجعه) · 🔴 غير موثوق/مش دايمًا موجود.

## الأعمدة اللي هتترفع
| العمود | المعنى | مصدره | ثقة |
|---|---|---|---|
| `status` | `auto` = كود المطابقة موثوق وفق القاعدة، `review` = لازم مراجعة | `export.status_for` | — |
| `item_code` | **كود الصنف في سوفتك** (أفضل اقتراح) | المطابقة (`docs/MATCHING.md`) | `auto` ≈ 97% (PharmaOverseas) |
| `item_name` | اسم الصنف في الماستر لنفس الكود | الماستر | ✅ |
| `qty` | الكمية | محسوبة (إجمالي ÷ السعر) ومتحقق منها بأنها عدد صحيح | ✅ PharmaOverseas · 🟡 ابن سينا |
| `bonus` | البونص | ابن سينا القديم فقط | 🔴 |
| `unit_price_net` | سعر الصيدلي (قبل الضريبة) | عمود «سعر صيدلي» | ✅ |
| `discount_pct` | خصم الصيدلي % | عمود الخصم | 🟡 |
| `vat_rate` / `vat_per_unit` / `vat_line` | الضريبة (14% / للوحدة / للسطر) | عمود الضريبة | ✅ للأصناف الخاضعة |
| `line_total` | إجمالي السطر | عمود «إجمالي القيمة» (PharmaOverseas) | ✅ |
| `public_price` | سعر الجمهور | عمود الجمهور | 🟡 |
| `batch` | التشغيلة | عمود التشغيلة | 🟡 (أحيانًا آخر رقم ناقص) |
| `expiry` | الصلاحية `YYYY-MM` أو `YYYY-MM-DD` | عمود الصلاحية | 🟡 96% PharmaOverseas |
| `margin_pharm` | هامش ثابت للصيدلي | عمود الهامش | 🟡 ~78% مقروء |
| `margin_dist` | هامش ثابت للموزع | — | 🔴 PharmaOverseas: فاضي (نص رأسي مطبوع فوقه) |
| `discount_tag` | `Reg` / `Oth` تحت الخصم | ابن سينا الجديد | 🟡 |
| `qty_printed` | الكمية كما هي مطبوعة | OCR | 🔴 خط اليد بيغطي عليها؛ للمقارنة بس |
| `supplier_on_invoice` | اسم الشركة المصنّعة على الفاتورة | OCR عربي | 🟡 |

## أعمدة للتعريف والتتبع (مش للرفع)
`supplier` · `invoice_key` (رقم أمر البيع/الفاتورة عند المورد) · `scan_date` · `file` · `pages` · `page` / `y` (صفحة السطر وموضعه، لقص صورته) · `line` · `template` · `layout` ·
`supplier_item_code` (كود الصنف عند ابن سينا الجديد) · `name_on_scan` (الاسم كما قُرئ).

## أعمدة المطابقة والتحقق
`match_score` · `match_gap` (الفرق عن المرشح التاني) · `alt_2` / `alt_3` (بدائل) · `learned_code` (الكود من ذاكرة التصحيحات) · `flags` (ملاحظات آلية عن قيمة اتصلحت أو مشكوك فيها) ·
`invoice_check` (`ok`/`mismatch`/`unknown`: هل إجمالي الأسطر بيطابق المطبوع، معلومة فقط) ·
`softec_doc` / `softec_code` / `softec_unit_price` / `code_agrees_with_softec` (لو الفاتورة اتربطت بإدخال سوفتك موجود، للمقارنة).

## قواعد للسكريبت اللي هيرفع
1. ارفع `status = auto` مباشرة. أسطر `review` تتراجع الأول في `review.xlsx` (بصورة السطر) ثم تتصدّر.
2. أي سطر `qty` فيه فاضي: ما يترفعش (يتراجع).
3. **السعر اللي هيترفع قرار مفتوح**: `unit_price_net` + الضريبة بيطابق سعر سوفتك للأصناف الخاضعة بالظبط (99%)، لكن للأصناف غير الخاضعة فيه فرق بسبب الهامش الثابت لسه ما اتحددش.
4. الأعمدة الجديدة بتتضاف دايمًا في الآخر، والأعمدة الموجودة ما بتتغيرش اسمًا أو معنى داخل نفس الإصدار.
